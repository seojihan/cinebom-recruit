# 씨네픽 1기 감독 · 평론가 모집 사이트

정적 HTML/CSS/JavaScript 사이트입니다. 깃허브 페이지로 공개합니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 모집 안내 (맨 위 실제 사이트 화면 캐러셀, 인사말, 모집 분야, 진행 순서, 심사 기준, 묻고 답하기) |
| `director.html` | 감독 지원서 (계획 · 마음가짐 · AI의 영향 · 작업 방식 · 1분 이내 예고편 첨부) |
| `critic.html` | 평론가 지원서 (영화 《원스》 · 시리즈 《도깨비》 별점 · 한 줄 평 · 평론) |
| `thanks.html` | 제출 뒤 나오는 감사 화면 |
| `privacy.html` | 지원자 개인정보 처리방침 |
| `config.js` | 이름 · 문의 메일 · **접수 주소** · 첨부 크기 · 글자 수 기준 |
| `assets/screenshots/*.jpg` | 캐러셀에 쓰는 씨네픽 실제 화면 |

## 지원서가 오는 길
지원자가 '지원서 제출하기'를 누르면 → 구글 Apps Script 접수기 → **Gmail로 지원서 전문**,
예고편 영상은 **구글 드라이브**, 목록은 **구글 시트**에 쌓입니다. 지원자는 메일을 따로 보내지 않습니다.

접수기 주소는 `config.js`의 `submitEndpoint`에 들어 있습니다. 비어 있으면 제출 버튼이 "접수 준비 중"이라고만 안내합니다.

접수기와 심사함 스크립트(`apps-script/`)는 지원 목록 시트 정보가 들어 있어서 이 저장소에 올리지 않고 운영자 컴퓨터에만 둡니다 (`.gitignore`).

## 깃허브 페이지
Settings → Pages → Branch를 `main` / `(root)`로 정해 두었습니다. 주소는 `https://<계정>.github.io/<저장소>/` 입니다.

## 홍보 링크 (어디서 왔는지 알기)
채널마다 주소 끝에 `?from=이름`을 붙여서 올리세요. 그 링크로 들어와 지원하면 지원서와 시트의 '들어온 링크' 칸에 그 이름이 남습니다 (60일 동안 기억).

| 올리는 곳 | 링크 |
|---|---|
| 링크드인 | `https://seojihan.github.io/cinepick-recruit/?from=linkedin` |
| 인스타그램 | `…/?from=instagram` |
| 디스코드 · 오픈채팅 | `…/?from=discord`, `…/?from=openchat` |
| 대외활동 사이트 | `…/?from=linkareer`, `…/?from=thinkgood` |
| 1:1 제안 메시지 | `…/?from=dm` |

지원서에는 '어디서 알게 되셨나요?'(선택) 칸도 있습니다.

## 링크 미리보기
카카오톡 · 링크드인 등에 링크를 붙이면 `assets/og.jpg`(1200×630)가 보입니다. 미리보기 태그는 사이트 주소를 그대로 적어 두었으니, 저장소 이름이나 주소를 바꾸면 세 HTML 파일의 `og:` 줄도 같이 바꾸세요.

## 고칠 때
파일을 고치고 다시 올리면(커밋 → 푸시) 1~2분 뒤 사이트에 반영됩니다. 문구는 대부분 `config.js`와 각 HTML 파일에 있습니다.
